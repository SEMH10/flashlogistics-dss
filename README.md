# FlashLogistics DSS

## Descripción

Sistema de Apoyo a la Toma de Decisiones (DSS) para optimizar la gestión logística de FlashLogistics.

---

## Visión del Producto

### ES

- Sistema inteligente de logística
- Plataforma de monitoreo en tiempo real
- Herramienta para toma de decisiones

### NO ES

- Sistema contable
- ERP completo

### HACE

- Optimiza rutas
- Rastrea vehículos
- Genera reportes

### NO HACE

- Gestiona nóminas
- Gestiona inventario completo

---

# Canvas MVP

| Elemento | Descripción |
|-----------|------------|
| Problema | Entregas tardías y altos costos |
| Solución | DSS con GPS y optimización de rutas |
| Usuarios | Gerente, Conductores y Clientes |
| MVP | Rutas automáticas, GPS y Dashboard |
| KPIs | Tiempo de planificación, entregas puntuales y combustible |

---

# Objetivo SMART

Desarrollar un DSS que reduzca en un 50% el tiempo de planificación de rutas y disminuya en un 20% las entregas tardías durante los próximos tres meses.
